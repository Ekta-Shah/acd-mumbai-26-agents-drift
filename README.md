# Agents Don't Crash, They Drift: deck and results explorer

AWS Community Day Mumbai, 25 minute talk plus 5 minutes of Q&A. Build plan: `PLAN.md`.

## What is here

| Path | What it is |
|---|---|
| `deck/drift-talk.pptx` | 16:9 deck on the ACD Mumbai 2026 template (`template/`): welcome and bio slides, 22 main slides, the template thank-you slide, then 4 appendix (A1 to A4), notes with timings, native charts, click-to-reveal animations, fade transitions, links |
| `demo/` | Runnable refund desk (Strands agents on Amazon Bedrock) that produces the real run. See `demo/README.md` |
| `video/` | Put `live-run.mp4` here; slide 11 links to it |
| `deck/slides.yaml` | All slide text and speaker notes. Edit this, not the code |
| `explorer/index.html` | The results explorer. One file, 24 KB, no network, embedded copy of the data |
| `explorer/index.template.html` | Source of the explorer. `make explorer` embeds `data/results.json` into it |
| `data/results.json` | Every number in the deck and explorer. Currently `"source": "illustrative"` |
| `export/` | `drift-talk.pdf` and one PNG per explorer state (backup if the laptop or wifi fails) |
| `scripts/` | `make_illustrative_results.py`, `build_explorer.py`, `build_deck.py`, `export.py`, `refresh.py`, `check.py` |

## Commands

```
make build       # data, explorer, deck
make export      # explorer PNGs, rebuild the deck with the backup PNGs in the notes, then the PDF
make check       # the acceptance checks from the plan (14 checks)
make refresh RUN=path/to/live-run.json   # swap in a live run, flip source to live-run, rebuild, export
```

Needs Python 3 with `python-pptx` and `pyyaml`, LibreOffice (`soffice`) for the PDF, and Google Chrome for the explorer PNGs (set `CHROME=...` if it lives elsewhere).

## Going live

A live run must follow the schema in `PLAN.md` (30 `daily` rows, 3 `events`, `runs` with at least `0000`, the four single patterns and `1111`, and a `summary`). `make refresh RUN=...` validates it, sets `meta.source` to `live-run`, and rebuilds. The ILLUSTRATIVE tag disappears and every chart rebuilds from the file.

## On the day

- Open the deck from its own folder. The explorer links are relative (`../explorer/index.html#scene=...`) and only work from there.
- Keep `explorer/index.html` open in a browser tab as well. If a link is blocked, switch to the tab. Scenes also have tabs and deep links: `#scene=catch&day=14`, `#scene=fix&p=1111`, `#scene=retention&pr=95&n=3`.
- Explorer keys: left and right arrows move the day, space plays, `1` to `4` toggle the patterns, `R` resets, `H` reveals the hidden panel in the green scene.
- Each explorer slide has a PNG of the same scene in its notes page, and all PNGs are in `export/`.
